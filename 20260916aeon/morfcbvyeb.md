# 【微医讯】海南医院心血管内科完成首例幼儿双孔型室间隔缺损封堵术

> 更新时间：2026-09-16 (UTC+8)

近日，解放军总医院海南医院心血管内科结构性心脏病团队，完成首例幼儿双孔型膜周部室间隔缺损合并膜部瘤的介入封堵治疗，标志着海南医院心血管内科治疗技术再上新台阶。

　　患儿蔡某年仅2岁，出生时查体发现心脏杂音明显，诊断室间隔缺损合并膜部瘤，原计划3岁时实施手术，但近期家属发现与同龄幼儿相比，其言语、行走能力发育明显滞后，急忙来到海南医院就诊。为保证患儿生长发育，心血管内科结构性心脏病团队在田进文主任带领下，充分进行术前评估，精心制定方案，迅速联合超声科、麻醉科及介入手术团队实施手术。

　　本次手术具有患者年龄小、结构复杂、操作难度大等特点，麻醉科、超声科、介入导管室医护团队全程精准保障。手术历时约2小时，术中左心室造影证实为双孔型室间隔缺损合并膜部瘤，患儿存在两处直径分别为4.58mm、1.85mm一大一小缺损，无形中给手术封堵增加了难度。团队成员密切配合、精准操作，最终将双孔型室间隔缺损成功封堵。微创介入封堵治疗，具有手术创伤小、术后恢复快等优势，术后患儿心脏杂音立即消失，预后良好，术后6小时即可下地行走，不到一周康复出院。

　　为实现“同质化建设”目标，海南医院持续大抓质量内涵建设，心血管内科在解放军总医院心血管病医学部王广义主任医师、韩宝石副主任医师等专家指导帮带下，逐渐形成了以周超飞副主任医师、付士辉主治医师及超声科王立波主治医师为代表的结构性心脏病治疗团队。截至目前，团队已独立完成成人及婴幼儿室间隔缺损、动脉导管未闭、卵圆孔未闭及肺动静脉瘘等各类结构性心脏病微创介入封堵治疗200余例，为广大结构性心脏病患者提供全面优质高效的医疗服务。

**科普小知识**　　在新生儿中，室间隔缺损的发生率约为3.0‰~3.5‰。室间隔缺损临床症状根据室间隔的缺损程度不同而有不同的临床表现，小型缺损无症状，一般活动不受限制；中度以上的室间隔缺损多表现为呼吸困难、心力衰竭、艾森曼格综合征，甚至影响生长发育，并发呼吸道感染和感染性心内膜炎。较大的室间隔缺损，易导致孩子反复发作感冒、肺炎或出现喂养困难、生长发育受限，严重影响患儿身体健康，建议尽早治疗。
